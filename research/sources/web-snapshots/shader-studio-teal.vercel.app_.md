# Universal Shader Studio

A browser-based GLSL shader editor built with React and Three.js. Write
vertex and fragment shaders live, preview on terrain or 3D models, and
export as Three.js ShaderMaterial, R3F component, raw GLSL, or vanilla
WebGL.

Features: live GLSL editor, procedural terrain, GLB model upload, shader
presets, multi-format export.

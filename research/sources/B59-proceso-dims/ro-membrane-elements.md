## The designation IS the dimension

> "The designation '4040' describes the physical dimensions of the element: 4.0 inches in diameter
> and 40 inches in length."

- 4040 element: 4.0 in x 40 in nominal — 101.6 x 1016 mm. Actual element diameter is quoted as
  3.9 in (99 mm), the clearance fit inside the vessel.
- 8040 element: 8 in diameter x 40 in length — 203 x 1016 mm.
- Membrane area, 4040: 78-85 ft2 typical, up to ~100 ft2 for high-area designs.
- BW-4040 duty point: ~2,400 GPD at 225 psi, 99.5 % salt rejection.
- Pressure vessels for 4040 elements: standard 4-inch housings, 300 psi and up, outer wrap of FRP
  (fibreglass reinforced plastic).

This is unusually hard evidence for a catalogue asset: the element length is a fixed 40 in, so a
vessel's length is set by how many elements it holds, not by styling. A 2-element vessel is
2 x 1016 mm of membrane plus end closures; a 3-element vessel is 3 x 1016. Getting the vessel
length wrong therefore contradicts an integer count of a standard part.
